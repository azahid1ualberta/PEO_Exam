# Past-Question Bank: Every Question, How Often It Repeats, What to Read

This file lists every question in all 28 unique past papers in this repo
(2013–2019), grouped by question type. Each group shows how many times it was
asked, which papers it appeared in, which questions were reprinted, and what to
read to solve it.

Companion files: [`STUDY_PLAN.md`](STUDY_PLAN.md) (the 45-day schedule) and
[`FORMULA_SHEETS.md`](FORMULA_SHEETS.md) (formulas and model answers).

## How to use this file

1. Start with **§1, Top targets**. Those are the questions that were reprinted
   word for word or nearly so. Solve these first.
2. Then work through each question type in §2 (B7) and §3 (A6) using the
   "Read" line. Do the textbook examples before the past-paper versions.
3. **§4** lists all 28 papers question by question, so you can find any
   question's topic tag.

## Legend

- **=** reprinted with the **same numbers** (an exact repeat)
- **≈** same problem with **small data changes**, or the same numbers restated
  (e.g., jam density given instead of capacity)
- **Current** = 2017–2019 papers (the 2016 syllabus you're writing). **Old** = 2013–2016.
- **Textbook** = Mannering & Washburn, *Principles of Highway Engineering and
  Traffic Analysis*, 5th ed.
  - "§3.4, p. 77" is the **printed** page number.
  - In a PDF viewer, **add 14** (printed p. 77 is PDF page 91).
  - The PDF's bookmarks also jump straight to each section.
- **G&H** = Garber & Hoel, *Traffic and Highway Engineering*. It covers what the
  textbook doesn't. Chapter numbers vary by edition, so the chapter topic is given.
